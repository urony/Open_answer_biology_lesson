# איך כותבים תשובה תהליכית

כלי אינטרנטי סטטי (בלי שרת) שמלווה שיעור בביולוגיה על כתיבת הסבר תהליכי.
מבוסס על המצגת "איך כותבים תשובה" (כיתה י').

## זרימה
1. שם התלמיד
2. תרגיל ראשון (שאלת CO), נכתב ונעול
3. לימוד (5 לשוניות, ניתן לפתוח גם מתוך התרגילים)
4. תיקון שאלת ה-CO בעזרת שרשור נסיבתי, עם משוב
5. השוואה ורפלקציה (ציון עצמי)
6. תרגול: שאלת דלקת ריאות, עם משוב
7. משוב למורה על השיעור
8. דוח PDF ושליחה בוואטסאפ

בכל שלב יש "פירוט: מה עושים בשלב הזה?" וכפתור "ללימוד" שמחזיר לתרגיל.
"מצב מורה" (בתחתית העמוד) פותח את כל השלבים.

## משוב
הבדיקה אוטומטית ולפי כללים, בלי בינה מלאכותית: ניסוח תכליתי או האנשה, קישורים סיבתיים, כיווניות,
רמות ארגון, מושגי מפתח לפי השאלה, אורך השרשור. הבדיקה מזהה מילים ולכן עלולה לטעות, והדבר כתוב לתלמיד.

## עריכה
- `content.js`: השאלות, מושגי המפתח, תשובות לדוגמה, ומספר וואטסאפ של המורה (`TEACHER_PHONE`).
- `app.js`: הלוגיקה והבדיקה (`analyze`).
- `style.css`: עיצוב.

## העלאה ל-GitHub Pages
Settings → Pages → Branch: `main` / root. הקבצים צריכים להיות בשורש הריפו.

## הרצה מקומית
`node .claude/serve.js` ואז http://localhost:5188
(אפשר גם לפתוח את `index.html` ישירות, ויצירת ה-PDF דורשת חיבור לאינטרנט בגלל ספריות מ-CDN).
